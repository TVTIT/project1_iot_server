Media Playback Example (Stage 8.6)

Minimal player exercising signed URL issuance, authenticated fetch, and near-expiry refresh.

Ready.
Security & Protocol Contract:
  • Tokens and signed URLs are kept strictly in page memory (no localStorage, sessionStorage, or cookies).
  • Signed URLs expire in ~120s; the client refreshes signed URLs on error recovery or near expiration on seek while preserving playback position.
  • Issuance route uses Cache-Control: no-store to prevent intermediate or browser caching of signed tokens.
  • Membership revocation immediately yields 404 for subsequent issuance requests.
  • Playback data plane listener, HTTP Range requests, and end-to-end browser media streaming are evaluated in Task 8.7.
